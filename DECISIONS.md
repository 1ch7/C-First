# EventPilot — implementation decisions

- Group: **C-First**. Campus: **Taylor's University**, defaulting to Lakeside Campus in Subang Jaya, Malaysia; exact event location remains editable.
- English only. Currency is **RM / MYR**, explicitly overriding generic currency defaults.
- Internal feature freeze: **2026-10-11 08:30 MYT**. Submission-ready target: **09:00 MYT**, preserving a 30-minute buffer before 09:30.
- Repository: `https://github.com/1ch7/C-First`. Isolated branch: `eventpilot-dormathon`. Never overwrite `main` or merge without the user's instruction.
- GitHub MCP integration returned HTTP 403 for branch creation. Existing Git credential authentication successfully created the requested remote branch without prompting. No tokens were inspected or copied.
- WorkBuddy keyless cloud activation returned `activated:false`, `cancelled:true`, `useLocalImplementation:true` after confirmation was dismissed. Follow that explicit fallback: Python standard-library HTTP service, SQLite, SSE, independent tool-using specialist actors. **No deployed LLM calls are claimed.** No invented credentials or model IDs.
- Lowest-risk single-port deployment: dependency-free Python service and vanilla responsive web UI. Production binds `0.0.0.0` via `HOST`; local verification binds `127.0.0.1`. SQLite persistence is real, but external backups and redeploy durability are not guaranteed.
- March without a year means the next future March (March 2027 at build time). Attendance defaults to 100. Organiser funding defaults to 70% of budget, creating a transparent 30% sponsorship target. All are assumptions, not supplied facts.
- Budget values are **planning allocations**, never vendor quotes. Arithmetic uses integer cents, with a 12% protected contingency reserve (validator minimum: 10%). Sponsor asks are alternatives sized to the gap, not committed funding.
- Weather within the provider's 16-day window uses forecast. More distant dates use same-calendar-day rain frequency and temperatures from ten observed years, labelled historical climatology, not a forecast. Missing data is unavailable, never fabricated.
- Rain thresholds (1 mm wet day; 20 mm heavy-rain day) and risk scoring are operational assumptions displayed transparently. A city geocode is a location proxy, not a precise campus weather station.
- Campus exam dates and venue reservations cannot be confirmed from public pages. Provisional holiday dates are not treated as official guarantees. Event Packs remain conditional on approvals, funding, roster and calendar confirmation.
- The default roster is empty; fictional availability appears only after explicit demo opt-in and remains labelled demo data. Editable/uploaded roster rows are user-provided assertions, not verified calendar free/busy. Private roster names and emails are redacted before public sharing.
- Gmail is draft-only. Five verified public event/partnership/marketing contacts are required before creating connector drafts. No guessed email addresses, no customer-service addresses presented as CSR contacts, no sending calls.
- Browser Gmail OAuth uses `gmail.compose` only; this scope technically permits sending as well, but EventPilot exposes only the draft-create endpoint. Without a Google client ID, visibly fall back to Gmail compose links, copy and `.eml` downloads. The WorkBuddy Gmail connector is a separate owner-authorized execution path, never exposed to visitors.
- Real recorded-run fallback must carry a persistent replay label and provenance timestamp; never render it as live execution.
- Scheduled T-14, T-7 and T-1 weather checks are durable SQLite jobs executed while the service is running. Sleeping/stopped hosting cannot guarantee execution; expose this limitation rather than promise an external scheduler.
- Submission evidence must distinguish pass, fail, not configured, and not verified. Report actual measured times and tool calls; no speculative hours-saved claim. Private Gmail receipt IDs and mailbox identity are excluded from public repository evidence.
- Ten real Gmail drafts (five initial sponsorship enquiries and five conditional follow-ups) were created through the authorised WorkBuddy owner connector on 2026-10-10 and independently found with DRAFT labels. This is separate from visitor browser OAuth, which remains unconfigured; do not inflate per-run browser Gmail counters.

Prior canonical browser flow passed; a subsequent restarted run failed with SQLITE_READONLY. - Non-charity workshops infer a disclosed editable learning objective rather than treating audience headcounts as beneficiaries. Activity-specific programmes, countdowns, risks and outreach avoid charity claims unless a charitable purpose is explicit.
